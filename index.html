Obsidian Backup

Obsidian Backup es una configuración personal que utilizo para realizar copias de seguridad de mis archivos de Obsidian en Google Drive mediante rclone.

La aplicación se utiliza exclusivamente para mi uso personal. rclone permite transferir los archivos directamente entre mi ordenador y mi cuenta de Google Drive.

Uso de los datos

La aplicación utiliza el acceso autorizado a Google Drive únicamente para realizar las operaciones de copia de seguridad que he configurado. No vendo, comparto ni utilizo los datos de Google para publicidad.
